## ✨ Key Features
- **Modern UI/UX**: Clean, minimal, and premium design with smooth animations.
- **Dynamic Themes**: Full support for Light and Dark modes with automatic theme detection.
- **Galaxy Effects**: Custom CSS-based star fields and floating cosmic elements (Active in Dark Mode).
- **Responsive Design**: Fully optimized for Desktop, Tablet, and Mobile devices.
- **Glassmorphism**: Sophisticated translucent effects across all major components.
- **Performance Optimized**: Built on Next.js 15 with App Router and optimized assets.
- **Dual Identity**: Showcasing expertise as both a **Full Stack Developer** and an **Islamic Scholar**.

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons (Si, Hi, Fa)
- **UI Components**: Custom Glassmorphism System
- **Fonts**: Geist Sans & Geist Mono

## 📂 Project Structure
- `src/app`: App Router pages and global layouts.
- `src/components`: Reusable UI components (Hero, Projects, About, Shared).
- `src/assets`: Local images and static assets.
- `public/screenshots`: Documentation visuals.

## 🛠️ Local Development
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) to view it.
